Koneksi Google Drive Storage Aktif

Simpan scan perjanjian di Google Drive, lalu tautkan di sini

Cara Menautkan Scan Perjanjian dari Google Drive:

  1. Unggah scan perjanjian (PDF / JPG) ke folder Google Drive.
  2. Klik kanan file (bukan folder) → Bagikan / Dapatkan tautan → akses "Siapa saja yang memiliki link".
  3. Salin link file itu dan tempelkan di form tambah/edit perjanjian.
